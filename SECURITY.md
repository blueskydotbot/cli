# Security policy

Please do not open a public issue for a security problem.

Report it privately to **security@bluesky.bot** (English or French), or with
GitHub's private vulnerability reporting on this repository. Include what is
affected, the impact and the steps to reproduce. Never include a real token.

You will get an answer within 72 hours. The policy of the whole project is at
https://bluesky.bot/security.

Only the latest published version of `@blueskydotbot/cli` (the `bsbot`
command) receives security fixes.
